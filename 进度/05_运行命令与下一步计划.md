## 五、评测一个预测

仅日期指标：

```powershell
conda run -n tls chronos-repro evaluate `
  --data ..\chronos_upstream\data\open `
  --topic Islamic_State_2019.10.27 `
  --prediction <预测文件.json> `
  --date-only `
  --output artifacts\scores_date.json
```

Windows 开发期完整指标：

```powershell
conda run -n tls chronos-repro evaluate `
  --data ..\chronos_upstream\data\open `
  --topic Islamic_State_2019.10.27 `
  --prediction <预测文件.json> `
  --rouge-backend reimpl `
  --output artifacts\scores_full.json
```

Linux/WSL 论文可比评测：

```bash
chronos-repro evaluate \
  --data ../chronos_upstream/data/open \
  --topic Islamic_State_2019.10.27 \
  --prediction prediction.json \
  --rouge-backend original \
  --output artifacts/scores_original.json
```
