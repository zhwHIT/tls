## 五、Date-F1 语义

预测日期集合记为 `P`，所有参考时间线日期的并集记为 `R`：

```text
precision = |P ∩ R| / |P|
recall    = |P ∩ R| / |R|
F1        = 2PR / (P + R)
```

空预测时 precision 与 F1 返回 0，不会出现除零错误。

需要注意：月份级和年份级时间被映射到当月/当年第一天，这是为了兼容 CHRONOS 上游行为，而不是声称事件真实发生在第一天。将来如研究不确定时间粒度，应改为区间或显式 granularity，而不能继续只用 `date`。

## 六、Timeline-ROUGE

| 指标 | 含义 |
|---|---|
| Concat | 将整条预测与参考时间线的所有日摘要拼接后计算 ROUGE |
| Agreement | 只比较预测和参考共同日期上的摘要 |
| Align | 按日期距离做一一对齐后计算内容重合 |
| Align+ | 对齐成本同时考虑日期距离与内容 |
| Align+ m:1 | 允许多个预测日期映射到同一参考日期 |

每种变体均计算 ROUGE-1 和 ROUGE-2 的 precision、recall、F1。

### 两种后端

#### `original`

调用原始 Perl ROUGE，是与 CHRONOS 和相关论文最严格可比的选择。当前 Windows 缺少 Perl，不能直接运行。

#### `reimpl`

Tilse 自带的 Python 近似实现，保留 stemming 和 stopword 处理，可在 Windows 上运行，适合开发、回归和消融趋势观察。它不保证与 Perl 得分完全一致。

所有输出均记录后端：

```json
"rouge_backend": "reimpl"
```

把金时间线作为预测应得到 1.0。这个测试证明：

- 时间线被正确读取；
