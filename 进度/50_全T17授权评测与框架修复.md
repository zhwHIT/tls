## 当前状态

已根据授权启动 T17 全部 9 个主题的 API 评测。本记录是运行中的检查点，不是最终验收报告。严格 gold 日期召回沿用每主题 70% 目标，gold 只用于离线评测。

## 框架及 prompt 审核后的修改

- 学生仍输出 1–3 条 SEARCH query 或 STOP；MEMORY_UPDATE、GAP_MEMORY、VERIFY、MERGE 由 API 执行。
- 事实摘要默认每 3 个查询批次更新；修订或上下文压力可以提前触发。摘要更新前继续向学生传递 verified event 的 APPEND、UPDATE、DELETE。
- 第二阶段 STOP 改为只暂缓当前 gap，调度器继续处理其他 gap。解决了“只判断当前问题，却一次取消全部问题”的作用域冲突，也避免向学生发送无限增长的完整 gap 目录。
- 已关闭 gap 的支持事件或锚点被修改、删除时，重新打开并清除旧证明；达到查询上限仍记为暂缓，不当作解决。
- 搜索 prompt 补充：换同义词不构成新信息需求，零增益后应转向不同的有依据线索或停止。
- CLI 与被导入模块共享同一异常类型，修复失败标签请求未进入主轨迹 usage 的异常路径。token 审计另外汇总所有已返回的在线响应，缓存重放不重复计费。
- 批次执行器允许记录单主题失败后继续其他主题；余额不足、源码变更仍停止。请求账本不重置。

输入继续使用 DeepSeek 官方 tokenizer 预检 3800、服务端实际输入上限 4096；学生输出上限 512。无需填充无关文字凑到 4K。这些设置不等于未来待训练模型 tokenizer 已验证。
