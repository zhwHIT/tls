# 最终答复证据越界与微宏平均纠错

日期：2026-09-17。本次针对用户指出的警告，核对对话最终答复、当前实现、62/63 号审计文档及 `evaluation_after_06.json`，不运行新的 API 评测。

## 核验结论

警告成立。问题发生在最终答复对已有证据的解释和指标命名上；不能用“模拟”“初步记录”或“工具截断”来保留这些不受支持的结论。

| 错误说法 | 正确说明 |
|---|---|
| 当时整体完成率 13/41 | 41 是剩余续跑批次，整体计划为 53；当时应为 13/53＝24.53%，续跑批次为 1/41＝2.44% |
| Egypt 召回未变证明 VERIFY 改动无损 | 父轨迹与继承其事件的续跑不是同条件新旧版本配对实验；只能报告这一次日期命中未变 |
| FINAL_SELECT 是独立原文复核 | 输入为 event_id、time、summary、conflict、evidence_ids，没有重新提供或检索原文；证据 ID 不等于证据正文 |
| 全部保留证明事件正确 | 只说明筛选没有删除事件；不能证明来源蕴含、日期正确或覆盖完整 |
| 383 项测试证明 Gold 不降 | 只说明所执行的离线断言通过；未测得修复版的在线 Gold 变化 |

修复版清单明确记录 `online_evaluation_of_patch=false`、`training_ready=false`。离线回放和 token 预检记录 `api_calls=0`，token 预检还明确 `semantic_validation=false`。不存在可据这些文件报告的新旧版本配对覆盖率结论。

## 上一条进度答复还有新的微宏平均错误

上一条答复把“按主题等权”称为微平均，并交换了微、宏结果，现撤回。

- 微平均：所有主题命中数之和 / 所有主题 Gold 数之和。
- 宏平均：各主题召回率的算术平均。

对 `evaluation_after_06.json` 中本批次已完成子集：

| 子集 | 微平均 | 宏平均 |
|---|---:|---:|
| Crisis，2 个完成主题 | 78/228＝34.21% | 34.13% |
| Entities，3 个完成主题 | 20/88＝22.73% | 28.92% |

这些只是明确选出的已完成子集，不是完整数据集成绩；原报告全量 aggregate 仍为 null。不同子集、版本及未完成状态必须保持标注。

## 原因分析

1. **统计对象混淆**：把整体计划已完成数与剩余批次总数相除，混用了分子、分母的范围。
2. **证据等级混淆**：将离线代码断言或单次继承续跑现象，提升成线上质量无回退结论。
3. **按步骤名称推断能力**：把最终筛选以及存在 evidence_ids 解释成重新读取原文；实际输入字段不支持这一解释。
4. **最终答复没有遵守已核实的限制**：62/63 号文档已正确限定结论，但答复再次删除限制、加入保证。不是单纯缺少数据，而是汇总时没有保持证据与主张一致。
5. **指标标签未与公式核对**：工具正确算出微宏平均，最终文字却交换名称和数值。
