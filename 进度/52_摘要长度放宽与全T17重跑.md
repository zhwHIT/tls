# 摘要长度放宽与全 T17 重跑

日期：2026-09-16。用户明确授权本轮修改和全量 API 重跑。

版本：`two-phase-v9.4-configurable-fact-length`。

## 调整

| 参数 | 前一轮 | 本轮 |
|---|---:|---:|
| 单条事实建议长度（字符，含空格） | 140 | 240 |
| 单条事实硬上限（字符，含空格） | 200 | 320 |
| 摘要事实条目上限 | 8 | 8 |
| 常规摘要更新间隔（检索批次） | 3 | 3 |
| DeepSeek tokenizer 输入预检上限 | 3800 | 3800 |
| API 实际输入硬上限 | 4096 | 4096 |
| 学生输出上限 | 512 | 512 |

长度由 `batch_controller.summary_fact_max_chars` 和 `summary_fact_target_chars` 配置，prompt、校验错误、修复提示及保守恢复使用同一组值。未指定的旧配置仍默认 200/140，历史回放入口保持可用。

总输入继续由 token 门禁控制，不能从字符上限直接推导所有未来请求都符合 4K。上下文压力触发摘要更新和分页的逻辑保持不变。

## 全量运行

已经启动单组串行执行，包含 bpoil、egypt、finan、h1n1、haiti、iraq、libya、mj、syria 全部 9 个主题；避免再次并行加载检索模型导致内存不足。

沿用完整评测规模：第一阶段最多 24 批，第二阶段最多 18 个检索周期，每批最多 3 条 query，每次 query 读取 2 个片段。每主题新账本最多 500 次 HTTP 尝试，本轮总上限 4500；实际请求数以账本为准。运行仍允许提前停止，不强制制造 gap 或填满查询次数。

模型、冻结数据、检索配置及 70% 严格 gold 日期召回目标保持不变；继承 v9.3 的错误恢复。新旧版本比较同时包含恢复逻辑与摘要长度变化，不应归因为单一参数的消融结果。

每个主题结束后自动执行本地评测，写入不可覆盖的阶段报告；失败、缺失主题保持可见。运行期间源码保持冻结。余额不足或源码变化会停止后续调用。
